# Formulario de Registro - Práctica UNEMI

Este proyecto consiste en un formulario responsivo desarrollado con **React** y **Bootstrap**.

## Requerimientos cumplidos:
- Migración de formulario a React.
- Uso de `useState` para control de inputs.
- Estilos con Bootstrap (`form-control`, `btn`, `container`).
- Validaciones dinámicas en tiempo real (correo y contraseña de 8+ caracteres).
- Diseño responsivo.

## Instrucciones de Instalación
1. Clonar el repositorio.
2. Ejecutar `npm install` para instalar dependencias (incluyendo Bootstrap).
3. Ejecutar `npm start` para iniciar la aplicación.
